# Backend

FastAPI + SQLite + LanceDB. Python 3.11+.

## Dependency Management

Three source files drive dependency installation:

- **`backend/requirements.txt`** — Production runtime dependencies (includes `lancedb`, `pyarrow`, `unstructured`, `sentence-transformers`).
- **`backend/requirements-ci.txt`** — CI runtime dependencies; excludes the heavy packages stubbed by tests to avoid multi-GB installs.
- **`backend/requirements-dev.txt`** — Development and test tools (`ruff`, `pytest` plugins, etc.).

The generated lockfiles **`backend/requirements-lock.txt`** and **`backend/requirements-lock-ci.txt`** are kept in sync with the source files above. Do not edit lockfiles directly — they are regenerated by the update scripts. The locks are **universal** (issue #567): platform-specific packages carry environment markers, so the same lock installs on Linux (CI, Docker) and Windows.

## Regenerating Lockfiles

Run the update script from the repo root (works on any platform — the locks are universal):

- Linux/macOS: `scripts/update-lock.sh`
- Windows: `scripts/update-lock.ps1`

Both scripts require `uv`. If `uv` is not available, the scripts install it automatically (`pip install uv`) before regenerating with `uv pip compile --universal --generate-hashes`. Procedure and verification details: [`docs/engineering/lockfiles.md`](../docs/engineering/lockfiles.md).

## Installing Dependencies

For production use:

```
pip install -r backend/requirements-lock.txt
```

For CI use:

```
pip install -r backend/requirements-lock-ci.txt -r backend/requirements-dev.txt
```

## Running Tests

```
pytest tests/
```

Run from the `backend/` directory. The project uses Python 3.11 in CI.
